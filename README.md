# Sidekick routes

The community library of **routes** for [Sidekick](https://github.com/gonzalocsv/sidekick-coach), the local-first meeting coach.

A route is a playbook for a situation: selling to the C-suite, holding a number in a negotiation, running a client
account. It is one Markdown file with a few focus skills, a path, achievements and practice drills. Sidekick
recommends a route from your profile; you follow one at a time. **Every achievement in every route is open to everyone,
whether or not they follow it.** A route only sets the order.

What lives here: route files and invented examples. What never lives here: transcripts, reviews, scores, or anything
about a real person or a real meeting. Your meetings stay on your Mac.

```
routes/<slug>/route.md     one route (see TEMPLATE.md)
index.json                 the catalogue, regenerated by a maintainer on merge; the app reads it when you click Browse
verified.json              author handles marked verified (Sidekick supporters)
```

## The website

The library will live on the Sidekick site (coming soon). The app never reads a web page; it reads `index.json`
from wherever it is hosted (`[routes] library_index` plus `library_hosts` in the app's config), and installs the route
files the index points at, checking each one's hash and lint. `docs/index.html`, generated with the index, is a
plain listing of the library that any host can serve as is; it carries no scripts beyond the role filter and nothing
about any user.

## Use a route

Sidekick ships with a snapshot of this library. Newer routes appear in **Growth › Routes › Browse library**. Install
copies the file to `~/Sidekick/routes/<slug>/route.md`; you can edit it there and Sidekick uses your copy.

## Write a route

In Sidekick: **Growth › Routes › New route** builds the file for you (tracks, path, achievements, drills, with the rules
checked as you type) and saves it to `~/Sidekick/routes/<slug>/`. **Share to the community** on that route replaces
every name Sidekick knows about, checks the file, and opens this repo's "new file" page with it filled in; GitHub forks
the repo for you and turns it into a pull request. Nothing is sent by the app itself.

By hand: read [CONTRIBUTING.md](CONTRIBUTING.md), copy [TEMPLATE.md](TEMPLATE.md) to `routes/<your-slug>/route.md`,
then paste it into the [submit form](https://learnwithsidekick.com/community/submit), which lints it as you type and
can open the pull request for you.
